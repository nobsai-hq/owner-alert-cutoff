Owner alert and follow-up cutoff

A free n8n add-on by No BS AI. When a missed-call lead replies, the owner is told right away, and automated follow-up stops. A STOP reply also cuts off follow-up.

This page is a browser sandbox Nothing is sent to a server

This page does not send texts, it does not write to a CRM, and it does not collect personal data. The real workflow is the n8n file in the GitHub repo. I have not yet run that workflow against a live Twilio number or a live owner alert.

What it does

  1. After the first missed-call text, you enroll the caller. A follow-up is scheduled (default: 2 hours later).
  2. If the caller writes back, the owner gets the message and later automated follow-up is skipped.
  3. If the caller replies STOP, follow-up is cut off too.
  4. Before every later send, the workflow re-reads that status. It does not try to cancel a Wait node.

It is an add-on to the missed-call text-back template, not a replacement.

How it works

  1. Import workflow.json into n8n.
  2. Edit the three Settings nodes so they share the same values.
  3. After your first text goes out, POST the caller to the Enroll Lead URL.
  4. Point your number's "a message comes in" webhook at Inbound Reply.
  5. Turn the workflow on. The 15 minute check only runs while it is Active.
